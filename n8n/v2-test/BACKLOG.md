## Source-date notes open plan sections

Status: open, not started. Recorded 2026-10-08 on Liz's instruction. Do not fix yet.

In generated plans, a caveat such as "Note: the source cited in this summary (S6) shows no publication date; the service description may have changed." is the first line of the Executive Summary, and the same kind of note opens sections 3, 4, 5, 8 and 11. It is accurate but it is the first thing a reader sees, before any content.

This must be addressed in the pipeline: decide where these notes belong (end of section, a single note near Sources, or inline with the citation) and change the writer or formatter accordingly. It is a pipeline change, not a sample correction.

The public adapted sample currently shows the notes as generated.

Found 2026-10-08 while reviewing the adapted sample.

Note for whoever picks this up: the review code checks these notes against the source record (finding "SOURCE DATE NOTE IS WRONG"), so moving or merging them means changing that check in the same change.
